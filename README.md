# Moral Dilemmas Simulator

## Description:
This Python project is an interactive simulator that presents users with moral and ethical dilemmas. Users select their choices, and all responses are recorded for analysis in both CSV and JSON formats.

## Features:
- Presents multiple moral dilemmas to the user
- Collects and timestamps user responses
- Saves responses in CSV and JSON files
- Designed for ethical and educational purposes
- Easy to extend with new dilemmas

## Installation:
Clone the repository:
git clone https://github.com/yourusername/Moral-Dilemmas-Simulator.git

Install required libraries:
pip install -r requirements.txt

## Usage:
Open the simulator.py file in Python or Google Colab and run it. Follow the prompts to answer dilemmas. Responses will be saved automatically.

## Requirements
Python 3.7+
No external libraries required beyond standard Python libraries (csv, json, datetime)
